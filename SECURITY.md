# Security Policy

## Supported Versions

Security updates are applied to the following versions of **checkpoint**:

| Version | Supported          |
| ------- | ------------------ |
| 0.9.x   | :white_check_mark: |
| < 0.9.0 | :x:                |

---

## Reporting a Vulnerability

We take the security and integrity of user game saves and cryptographic routines very seriously. If you discover a security vulnerability in checkpoint, please follow these guidelines:

1. **Do not create a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by emailing the project maintainers directly.
3. Include the following details in your report:
   - Type of vulnerability (e.g., path traversal, command injection, credential exposure).
   - Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
   - Expected vs. actual behavior and potential security impact.
   - Operating system and version of checkpoint.

### Our Response Process

* We will acknowledge receipt of your vulnerability report within 48 hours.
* We will investigate and provide an estimated timeline for remediation.
* A security advisory and patched release will be published once the issue has been resolved.
* Responsible disclosures will be publicly credited in our release notes (unless anonymity is requested).

Thank you for helping keep **checkpoint** safe for all gamers! 🛡️
